Privacy Policy – Life_app

Last updated: November 18, 2026

Who uses this app

Life_app is a personal desktop tool used only by its developer to manage the developer's own YouTube channels. It is not distributed to or used by the public.

Data accessed through Google APIs

  • YouTube Data API: uploading the developer's own videos, setting titles, descriptions, captions, thumbnails and scheduled publish times, and reading basic channel information.
  • YouTube Analytics API: reading the performance data of the developer's own channel (views, watch time, audience retention, audience age/gender, traffic sources) to create private reports.

How data is stored and shared

  • OAuth tokens and reports are stored only on the developer's own computer.
  • No data is sold, shared with third parties, or used for advertising.
  • Summaries of the developer's own channel statistics may be processed by an AI assistant chosen by the developer to write reports; no other users' personal data is processed.

Google API Services User Data Policy

Life_app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. This app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the app's data folder on the computer removes all stored tokens and reports.
